# Trad Sunset Suite for Rainmeter Native

A cyberpunk-inspired, hardware-monitoring desktop widget suite built natively for Linux on Wayland using `rainmeter-native`.

## Included Fonts
- Orbitron (Display Clock)
- Rajdhani (Headers & Dates)
- Share Tech Mono (Digital Metrics)

## Installation
Place the `TradSunset` folder into your `~/.config/rainmeter-native/Skins/` directory and launch via the engine:
\`\`\`bash
rainmeter-native ~/.config/rainmeter-native/Skins/TradSunset/TradSunset.ini
\`\`\`
